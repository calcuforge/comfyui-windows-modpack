# ComfyUI Windows Modpack

A Windows extract-and-run modpack ported from the Docker image built by `docker/comfyui/comfyui_with_nodes.Dockerfile`.

[中文文档 / Chinese documentation](README.zh-CN.md)

**Includes:** ComfyUI, 46 custom nodes, SageAttention, isolated Qwen3-TTS / Qwen3-ASR runtimes, and automatic model downloads.

## Directory Layout

```
comfyui-windows-modpack/
├── init.bat                    # Init script (venvs / ComfyUI / nodes / SageAttention / models)
├── run.bat                     # One-click launcher (auto-runs init.bat on first start)
├── qwen3_asr_requirements.txt  # Dependency list for the Qwen3-ASR venv
├── README.md                   # This document (English)
├── README.zh-CN.md             # Chinese documentation
├── init.log                    # Init log (generated by init.bat; console and log in sync)
├── python_comfyui/             # ComfyUI main venv (generated by init.bat)
├── python_qwentts/             # Qwen3-TTS isolated venv (generated by init.bat)
├── python_qwenasr/             # Qwen3-ASR isolated venv (generated by init.bat)
├── SageAttention/              # SageAttention source (generated by init.bat)
├── ffmpeg/                     # FFmpeg binaries, shipped in-package (generated by init.bat)
└── ComfyUI/                    # ComfyUI + custom_nodes + models (generated by init.bat)
```

## System Requirements

| Item | Requirement |
|---|---|
| OS | Windows 10/11 64-bit |
| GPU | NVIDIA, Ampere (30-series) or newer recommended |
| VRAM | 12GB+ recommended (depends on models) |
| Python | **3.13** (required, same as the Docker image; the script refuses to run without it) |
| Git | https://git-scm.com/download/win |
| CUDA Toolkit | 12.8+ (only needed to **build SageAttention from source**; optional — falls back to the pip wheel) |
| VS Build Tools | C++ desktop workload (only needed for SageAttention source build) |
| Disk | ~20GB environment + 80GB+ models (model download can be skipped, see FAQ) |

## Quick Start

1. Extract the package to any folder (avoid non-ASCII characters and spaces in the path).
2. Double-click `run.bat` — the first run automatically executes `init.bat` (takes a while, includes model downloads).
   Or run `init.bat` manually first, then `run.bat`.
3. The browser opens `http://127.0.0.1:8188` automatically **once the server is ready** (the launcher polls the port; no fixed delay).

## What init.bat does

| Step | Content |
|---|---|
| 0 | Check Git / Python 3.13 / NVIDIA GPU (nvidia-smi) / nvcc |
| 1 | Create 3 isolated venvs from the system Python: `python_comfyui`, `python_qwentts`, `python_qwenasr` |
| 2 | Clone ComfyUI |
| 3 | Install PyTorch cu130 (Aliyun mirror, auto-fallback to the official index) + ComfyUI requirements |
| 4 | Clone 46 custom nodes and install their requirements one by one (Qwen3-TTS/ASR installed in their own venvs) |
| 5 | Qwen3-TTS venv: soundfile + ComfyUI-Qwen3-TTS deps (qwen-tts etc.) |
| 6 | Qwen3-ASR venv: qwen-asr / modelscope / transformers==4.57.6 etc. |
| 7 | Build SageAttention (auto-detects GPU compute capability; falls back to the pip wheel without nvcc) |
| 7.5 | Download FFmpeg into `ffmpeg/` (BtbN win64 build; github direct -> ghfast -> ghproxy fallback) |
| 8 | Download all models (Qwen-Image / Wan2.2 / LTX-2.3 / Z-Image / Stable-Audio-3 / Qwen3-TTS / Qwen3-ASR / IndexTTS-2 etc.; existing files are skipped, safe to interrupt and resume) |

All steps are idempotent — re-running skips what's done.

**Logging:** every line init.bat prints (including stderr) is teed to `init.log` (UTF-8) while the console shows it live. Script messages are English because cmd.exe cannot reliably parse Chinese inside .bat files.

**Why three separate venvs (same as Docker):** qwen-tts pins `transformers==4.57.3` while qwen-asr pins `transformers==4.57.6` — mutually exclusive versions that must be isolated. The custom nodes locate their interpreters via the `QWEN_VENV_PYTHON` / `QWEN_ASR_VENV_PYTHON` environment variables set by `run.bat`.

## FAQ

**Q1: Downloads are too slow or fail?**
The script uses `HF_ENDPOINT=https://hf-mirror.com` (China mirror) and the Tsinghua PyPI index, same as the Docker image. Git clones retry via ghfast.top / ghproxy. Failed items resume on the next `init.bat` run. git clones also have low-speed timeouts so a hung proxy fails fast instead of hanging forever.

**Q2: Don't want to download all models?**
Either:
- Run `init.bat --no-models` (environment only), or
- Edit the top of `init.bat`: change `set "SKIP_MODEL_DOWNLOAD=0"` to `1`.

Then download only what you need manually.

**Q3: pynini fails to install?**
pynini has no official Windows wheels — this is expected. Qwen3-TTS does not depend on it and works fine.

**Q4: SageAttention build fails?**
You need CUDA Toolkit 12.8+ (with nvcc) and VS Build Tools (C++ workload). ComfyUI still works without it — only attention acceleration for long videos etc. is affected. The script falls back to the pip wheel automatically.

**Q5: Not enough VRAM?**
Edit `CACHE_RAM=46.5` in `run.bat` (WanVideoWrapper cache cap) to about half your VRAM, e.g. 6 for a 12GB card.

**Q6: Change the port?**
Edit `--port 8188` and the URL in `run.bat`.

**Q7: Redistribute the package?**
Delete `ComfyUI/`, `python_*/`, `SageAttention/` and zip it up. Receivers just unzip and double-click `run.bat`.

## Notes

- Environment variables set by `run.bat`: `QWEN_VENV_PYTHON`, `QWEN_ASR_VENV_PYTHON` (used by the Qwen3-TTS/ASR nodes to locate their interpreters), `HF_ENDPOINT` (mirror), `CACHE_RAM` (WanVideoWrapper VRAM cache cap), and `PATH` prepended with the package's `ffmpeg\bin` so all nodes (VideoHelperSuite, ffmpeg-python, etc.) find FFmpeg.
- Python 3.13 is required (same as the Docker image, which uses python3.13). Detection: `py -3.13`, falling back to a `python` on PATH that reports 3.13.
- PyTorch cu130 is installed from the Aliyun wheel mirror first, falling back to the official `download.pytorch.org/whl/cu130` index, then the default index.
- `pynini` has no Windows wheels — installation is best-effort and skipped with a warning; Qwen3-TTS works without it.
- deepspeed (a dependency of the IndexTTS node) cannot be built on Windows. The node's other dependencies are installed package-by-package, skipping the broken ones — the IndexTTS node loads and works.
- The removed ComfyUI-NAG and ComfyUI-QwenImageLoraLoader nodes are intentionally not included.
- All steps are resumable: re-running `init.bat` skips existing venvs, clones, installed packages, and downloaded models.
